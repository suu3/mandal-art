개인정보처리방침

시행일: 2026년 10월 19일 · 만다라트

만다라트는 개인 목표 보드를 작성하고 진행 상황을 확인하는 서비스입니다. 다음은 현재 서비스에서 처리하는 정보와 사용 방식입니다.

처리하는 정보와 목적

Google 또는 GitHub 로그인 시 계정 식별자, 이름, 이메일, 제공되는 프로필 이미지와 이메일 인증 상태를 받아 계정을 식별하고 개인 보드 접근을 관리합니다. 로그인 제공자가 발급한 인증 토큰과 서비스 세션 정보를 인증 라이브러리를 통해 저장할 수 있습니다. 세션에는 접속 IP 주소, 브라우저 정보, 생성·만료 시각이 포함될 수 있습니다.

사용자가 입력한 보드 이름, 목표, 메모, 우선순위, 기한, 완료 상태와 생성·수정 시각을 보드 제공·저장·동기화에 사용합니다. Google 로그인은 openid·기본 프로필·이메일만 요청하며 Gmail, Drive, Calendar 데이터는 요청하지 않습니다.

저장과 외부 서비스

로그인 계정과 보드 데이터는 Cloudflare Workers 및 D1에서 처리·저장합니다. Google과 GitHub는 각 로그인 제공자로서 인증을 처리합니다. Google 사용자 데이터는 로그인과 사용자가 요청한 서비스 기능 제공에만 사용하며 광고, 판매 또는 AI 모델 학습에 사용하지 않습니다. 사용자의 지시, 서비스 운영에 필요한 처리, 보안 또는 법령상 의무가 있는 경우를 제외하고 제3자에게 제공하지 않습니다.

로그인하지 않은 기기 보드와 화면 설정은 해당 브라우저의 localStorage에 저장됩니다. 로그인 세션은 쿠키를 사용합니다. 공개 정적 파일은 서비스 워커에 캐시할 수 있지만 인증·보드 API 응답은 캐시하지 않습니다. 기기 보드를 로그인 계정으로 자동 업로드하지 않습니다.

보관과 삭제

계정과 클라우드 보드 정보는 서비스 제공을 위해 보관합니다. 화면에서 보드를 삭제하면 목록에서 숨기는 논리 삭제가 적용되므로 즉시 영구 삭제되지는 않습니다. 계정·보드의 영구 삭제 또는 열람·수정을 원하면 아래 연락처로 요청할 수 있습니다. 운영 백업에는 삭제 전 데이터가 남을 수 있으며 삭제 요청 시 백업에 남는 정보도 함께 검토합니다.

기기 보드는 브라우저의 사이트 데이터 삭제로 지울 수 있습니다. Google 계정의 연결된 앱 설정에서 접근 권한을 철회할 수 있으며, 권한 철회만으로 이미 저장된 서비스 데이터가 자동 삭제되지는 않습니다.
